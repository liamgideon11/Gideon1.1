## What Gideon is
A personal AI voice assistant, inspired by the ship's-computer AI "Gideon" from *The Flash*, but with an **original** look and voice. We deliberately don't copy the show actress's face or voice, and we don't use DC assets.

- A **3D holographic glass head and shoulders** (Three.js) in front of a studded metal wall with wispy light streaks.
- You talk to it by voice or text. It answers out loud with **lip-sync** and blinks.
- A **wake word**: say "Gideon" while the app is open.
- The brain is **Google Gemini (free tier)**, with optional Google Search grounding.

## How index.html is organised (top to bottom)
1. **Meta tags:** Home Screen web-app tags (`apple-mobile-web-app-capable`, status bar, title, icon), `viewport-fit=cover`.
2. **CSS:** dark sci-fi theme (Orbitron + Inter fonts). `#stage` has the studded wall drawn in pure CSS (two repeating radial gradients) plus a fade. There's also the chat log, a control bar, the `.modal` settings card and the `#boot` "TAP TO ACTIVATE" overlay.
3. **HTML:** header (title, status line, ⚙︎ button), `#stage` holding `<canvas id="wisps">` (2D) and `<canvas id="orb">` (WebGL head), `#log` chat, `#heard` (live transcript), `#note` (yellow warnings), the form (🔊 voice toggle, 🎙️ talk once, 👂 wake-word toggle, text input, SEND), `#boot` overlay and `#settings` modal (key, model, name, city, voice select, speed/pitch sliders, test voice).
4. **`SYSTEM` prompt:** Gideon's personality (calm, formal, dry wit, short spoken answers, no markdown, teen-appropriate). It has `{NAME}` and `{CITY}` placeholders, and the current date/time is appended at call time.
5. **3D head (`buildHead`, `ICE_PARTS`, `iceField`)**
   - **v3.1 (current):** `META` lists the revised script's metaballs `mb(loc, radius, sx, sy, sz)` (axes mapped as below) plus an added back-of-skull blob. `iceField` = `META_THRESHOLD(0.78) − Σ STIFF(2)·(1−q)³` with `q = |(p−c)/size|² / (r·reach)²`; reach is 1.9 for big blobs and 1.5 for small ones, so a lone blob's surface sits near its radius as in Blender. Y is divided by `META_TALL=1.08` (the script's final stretch). `ICE_SCALE=0.38`. Many script features (brows, lips, ears) sit inside the skull blob, so the face is deliberately soft and ghostly. Eyes are `ICE_EYES` at z 0.98 (the script's -1.05, slightly into the face).
   - (v3.0, superseded) The face followed the first reference script: `ICE_PARTS` listed its ellipsoids (Head, Jaw, cheeks, nose bridge/tip, lips, chin, brows, ears) with Blender axes mapped to ours (Blender x→x, z(up)→y, −y(toward camera)→z), scaled by `ICE_SCALE = 1/2.9`. Deliberate tweaks (commented in code): Head depth 0.75→1.0, an added back-of-skull ellipsoid, shorter nose bridge, slightly smaller nose tip, eyes a little deeper.
   - `iceField(x,y,z)` = smooth union (k=0.26) of approximate ellipsoid distances. `buildHead` takes a `SphereGeometry(1,150,150)` and, for each vertex direction, marches a ray inward from r=3.2 from centre `C=(0,-0.3,0.35)` until inside, then bisects, giving ONE smooth mesh (≈0.4 s on desktop).
   - `ICE_EYES` = the script's glowing "Glass eye" ellipsoids as separate meshes in `headGroup` (simple fresnel ShaderMaterial); they blink by scaling y (`e.userData.sy`).
   - Per-vertex data computed from position: `jawW` (soft weights below `ICE_MOUTH_Y=-0.87`), `mouthW`, `gap` (lip line, always faintly dark, darker when open). `blinkD`, `irisA`, `aFace` are zero (kept so the shader/animation code is unchanged). Jaw pivot is `H.pivot`. Only the `moving` vertex list is updated each frame.
   - `EYE_X/EYE_Y/MOUTH_Y`, `FK`, `fsp()` remain only for the shader's (now inert) eye-shade term.
   - **Shader** (`ShaderMaterial`): a see-through icy-blue look (alpha ≈0.62 + Fresnel, blue edge glow, faint dot grid, occasional glitch line). Older notes: It mixes dark blue to white by key/fill lighting, adds a Fresnel edge glow, a specular highlight, faint animated "veins" (thresholded sines), soft scanlines and a sweep band. Uniforms: `uTime`, `uLevel`, `uOpen`, `uBlink`, `uFade`.
   - **Bust:** a `LatheGeometry` neck and shoulders, flattened front-to-back, that fades out at the bottom. The head sits in `headGroup` (scale 0.9). Projector rings and floating particle motes surround it.
   - Drag to rotate (pointer events). Idle sway and bob.
6. **Lip sync:** `VISEME` maps each letter to [jaw open, lip round]. `speechSynthesis` `onboundary` word events drive `lipStartWord()`. If a voice gives no boundaries, `lipWholeText()` estimates the timing. The animation loop eases `mouthOpen` and `mouthRound`.
7. **Voice (TTS):** browser `speechSynthesis`, through a **sentence queue** (`talker`): `talkStart(after)` → `talkPush(text)` (split by `splitSentences`, which needs a space after `.!?` so decimals survive) → `talkEnd()`; `after` runs when the queue empties. `speak(text, after)` wraps all three. `stopTalking()` cancels instantly (tap on the head via `onHeadTap()`, mic button, mute). Each queue has a `gen` number so callbacks from cancelled speech are ignored. The user picks a voice, speed and pitch in Setup (stored as `gideonVoice`, `gideonRate`, `gideonPitch`). iOS requires a user tap before any audio, so the `#boot` overlay handles the first tap. `speak(text, after)` runs the `after` callback when finished; it's used to resume listening.
8. **Listening (STT):** `webkitSpeechRecognition`.
   - `startRec('query')` listens for one question and sends it after a 1.4 s pause.
   - `startRec('wake')` listens continuously. `findWake()` does fuzzy matching (edit distance ≤2 for words starting with g/j/k, ≤1 otherwise; also handles two-word splits like "giddy on"). Saying "Gideon …" sends the rest directly; saying just "Gideon" makes it speak "Yes?" and then listen for the question.
   - **Conversation mode** (`convo`, Setup option `gideonConvo`, default on): after a voice question, `afterReply()` calls `listen()` (query mode with an 8 s `FOLLOW_MS` window that restarts Safari's recogniser on silence) instead of going back to the wake word. Follow-ups are sent with `{follow:true}`, which appends `FOLLOW_NOTE` so Gemini replies `[IGNORE]` if the speech wasn't meant for it (the bubble is struck through and convo ends). It ends on: `DISMISS` regex match ("that's all", "bye", "never mind"… handled locally, no API call), Gemini's `[END]` tag, silence, or `[IGNORE]`. Saying "Gideon" in a follow-up forces `follow:false`.
   - `keepAwake()` uses the Screen Wake Lock API while the wake word or a conversation is active, because a locked screen kills the mic.
   - Recognition stops while Gideon speaks or thinks. A watchdog restarts it every 3 s, it's force-restarted every ~50 s, and it resumes when the page becomes visible again.
9. **Brain:** `callGemini(model, useSearch, quick, onText, extra)` POSTs to
   `https://generativelanguage.googleapis.com/v1beta/models/{model}:streamGenerateContent?alt=sse` (streaming: SSE `data:` lines parsed as they arrive; `onText` gets the text so far, and `sendText` speaks each finished sentence right away; idle timeout 20 s) with header `x-goog-api-key`. The body has `system_instruction`, plus `contents` (the last 20 turns, with roles user/model), optional `tools:[{google_search:{}}]`, and `thinkingConfig.thinkingLevel:'low'` for `gemini-3*` models. Each request is aborted after 25 s.
   - `askGemini(onText, extra, wantSearch)`: `availableModels()` lists the key's real Flash models via `GET /v1beta/models` (cached a day in `gideonModels`, Lite first). It tries the chosen model, then the others, at most **5 attempts / 40 s**. Search is used only if `needsSearch(text)` (weather, news, scores, today…) and is dropped on a 429/400/403. Models that return 429 are rested in `gideonTired` until their limit resets (uses Google's "retry in Xs"; daily limits rest 1 h). It stops at once on a bad key, no internet, or `cancelThinking()` (tap head/mic while thinking). It remembers the working model. Errors show in `#note` as "Google says: …".
   - **Free-tier reality (Oct–Nov 2026 reports, conflicting):** 3.8 Flash ≈ 20 requests/day, Flash-Lite ≈ 500/day, Pro has no free tier. That's why Lite is the default.
10. **Settings:** the `store` helper wraps `localStorage` in try/catch. Keys: `gideonKey`, `gideonModel` (default `gemini-3.5-flash-lite`; a one-time `gideonV23` migration moves any non-Lite choice to Lite). A fallback model is only saved as the new choice if the chosen one 404s, never just because it was out of quota., `gideonName` (default Liam), `gideonCity`, `gideonVoice`, `gideonRate`, `gideonPitch`, `gideonMemory` (JSON array of facts), `gideonTimers` (JSON array of `{id,end,label}`).
11. **Instant answers:** `localAnswer()` answers time/date questions on the phone with no API call.
12. **Chat restore:** `history` is saved to `gideonChat` with a timestamp; if reopened within 30 min, bubbles are restored and the greeting becomes "Welcome back". Setup has CLEAR CHAT.
13. **Action tags:** the `SYSTEM` prompt teaches Gemini to add hidden tags to replies. `applyActions()` strips them and acts on them before the reply is shown or spoken:
    - `[TIMER: seconds | label]` → `addTimer()`. Timers store an absolute `end` time, so they survive reloads. A 1 s interval rings due timers (`chime()` via WebAudio + spoken message + alert mood), but only after the boot tap and never while speaking/thinking. Overdue timers say "While I was offline…". Timer chips in `#timers` show the countdown; tap one to cancel.
    - `[END]` ends conversation mode after the reply; `[IGNORE]` (follow-ups only) drops the message silently. `stripTags()` hides tags (including half-arrived ones) while streaming; `applyActions()` acts on them once at the end.
    - `[CANCEL]` clears all timers. `[REMEMBER: fact]` → `remember()` (max 40, de-duplicated). `[FORGET]` clears memory. `[MOOD: alert|happy]` → `setMood()`.
    - Tag names must not contain `_ * # \``, because `callGemini()` strips those characters.
    - Memory facts and running timers are appended to the system prompt on every call. Setup shows the memory list with a FORGET MEMORIES button.
14. **Boot sequence:** the `#boot` tap unlocks WebAudio + speech (it speaks "Initializing." inside the tap; a silent/blank utterance does NOT unlock iOS), plays `powerUpSound()` (filtered sawtooth sweep + two pings), types status rows into `#bootLog` (real checks: 3D, voices, mic, key, memory count), fills `#bootBar`, removes `body.cold` so the hologram fades in, then greets after 2.1 s and sets `booted`.
15. **Moving eyes:** irises are drawn in the fragment shader around `eye centre + uLook`, using the per-vertex `aFace` attribute (face-space x,y) and `aIris` as an eyeball mask, plus pupils and catch-lights. `updateEyes()` sets `lookGoal`: random glances (saccades) when idle, up-and-aside while thinking, at the viewer while speaking; `lookAt(nx, ny, ms)` points them toward a tap on the stage.
16. **Notes / to-do:** tags `[NOTE: item]`, `[DONE: number or words]`, `[CLEARNOTES]`; stored in `gideonNotes` (max 50), listed in the system prompt and in Setup (CLEAR NOTES). The prompt also asks for a 3–5 sentence **briefing** on "good morning" / "briefing" / "what did I miss" (date, weather via search, timers, top 3 notes).
17. **Mood colours:** `MOODS` holds `tint` (multiplies the shader colour via the `uTint` uniform, shared by head and bust) and `glow` (sets the CSS `--glow` var, so the title and buttons recolour too). Thinking = purple automatically, alert = red (timers, errors, `[MOOD: alert]`), happy = gold, calm = ice blue. `updateMood()` eases toward the target every frame.

## History (what we tried and learned)
1. **v1 was built as a claude.ai artifact.** It used Claude through the artifact `sample` capability, which needs no key. Inside the Claude app's sandbox, though, the **mic and sound are blocked**, so we moved to a standalone page in Safari.
2. The head evolved from a 2D canvas orb, to a 2D head, to a Three.js sphere head, to a refined, frosted-glass, bust version styled after a reference image. The style was copied (icy glass, studded wall, wisps); the face is original.
3. Gemini setup issues:
   - `gemini-2.5-flash` returned 404, because it's retired.
   - Usage-limit (429) errors, which were likely caused by search grounding or the model not being free on the key. That's why the fallback loop and search auto-disable exist.
4. GitHub Pages issues: README showing instead of the app (index.html was missing at first), 404s from wrong capitalisation (`/Gideon/` vs `/gideon/`), and Safari caching. Add `?v=N` to the URL, and re-add the Home Screen icon after updates.
5. The Google AI Studio account must be 18+. Liam's key was made by an adult. Don't help bypass age checks.

## Known limitations / open issues
- **Timers only ring while Gideon is open on screen** (no background notifications for web apps without a server). If the app was closed, an overdue timer is announced the next time it opens.
- **Wake word only works while the app is open and on screen.** iOS doesn't allow background listening for web apps. Safari speech recognition is flaky: it stops on silence and sometimes needs a tap (the status shows "Mic paused, tap 👂"). The mic may not work at all in Home Screen (standalone) mode on some iOS versions; Safari is the fallback.
- **Background / hands-free use** is done with the Siri Shortcut in `SIRI-SHORTCUT.md` (Repeat loop: Dictate → dismiss check → Gemini → Speak, until "that's all"/silence/[END]), triggered by "Hey Siri, Gideon" or an iOS 18 **Vocal Shortcut** on the word "Gideon". The shortcut can't see the web app's memory or timers. If the model 404s, update the model name in the shortcut's URL too.
- Siri's own voices aren't available to web pages. The best results come from downloading Enhanced/Premium voices (Settings → Accessibility → Spoken Content → Voices).
- Gemini model names change over time. If you get a 404, check the current free Flash models.
